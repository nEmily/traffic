# Traffic — Crowd Simulation

> **Live Demo:** [https://nemily.github.io/traffic/](https://nemily.github.io/traffic/)

A real-time crowd simulation built in Unity using NavMesh pathfinding. Agents navigate dynamically around each other and obstacles, demonstrating emergent crowd behavior.

## Tech Stack

- **Engine:** Unity
- **Language:** C#
- **Pathfinding:** Unity NavMesh
- **Platform:** Windows (standalone executable)

## Running the Simulation

### Option 1 — Download and run (Windows)

Download and unzip `crowdsimulationexecutable.zip` from the repository, then run the executable.

### Option 2 — Open in Unity

1. Clone the repository
2. Open the `crowd simulation` folder as a Unity project
3. Open the project in the Unity Editor and press Play
